# Rewiza Tech — GitHub Pages starter

Paket ini adalah kerangka awal website statis untuk repository `rewizatech.github.io`.

## Isi
- `index.html` — beranda
- `about/` — tentang Rewiza Tech
- `apps/` — daftar aplikasi dan profil Rewiza Smart Compress
- `privacy/` — indeks kebijakan privasi dan penanda status draf
- `faq/` — indeks bantuan dan FAQ
- `contact/` — kontak email
- `assets/style.css` — tampilan responsif

## Cara memasang melalui GitHub di ponsel
1. Buka repository `https://github.com/rewizatech/rewizatech.github.io`.
2. Pilih **Add file** → **Upload files**.
3. Ekstrak ZIP ini terlebih dahulu di perangkat. Upload isi folder paket (bukan folder induknya) ke root repository.
4. Pastikan `index.html` berada sejajar dengan `README.md`, bukan di dalam subfolder tambahan.
5. Commit changes ke branch `main`.
6. Tunggu GitHub Pages selesai deploy, lalu buka `https://rewizatech.github.io/`.

## Catatan penting
- Kerangka ini belum merupakan website final.
- Halaman Privacy Policy Rewiza Smart Compress secara eksplisit berstatus DRAFT dan tidak boleh dipakai sebagai tautan kebijakan resmi Google Play.
- Isi Privacy Policy final dan Data Safety harus menunggu audit implementasi, permission, SDK pihak ketiga, dan alur data aktual.
- Informasi WhatsApp belum ditautkan karena format nomor internasional belum dikonfirmasi.
- Tautan Play Store belum dicantumkan karena listing resmi belum tersedia.
