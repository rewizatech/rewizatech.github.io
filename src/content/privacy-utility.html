Kebijakan Privasi: Aplikasi Utilitas

Terakhir Diperbarui: 10 November 2026 · Berlaku untuk aplikasi utilitas Rewiza Tech (termasuk Rewiza Smart Compress)

Kebijakan Privasi ini mengatur bagaimana Rewiza Tech memproses data dalam kategori aplikasi utilitas dan produktivitas Android. Kami mengedepankan pemrosesan data lokal (on-device processing) untuk memastikan keamanan privasi berkas pengguna.

Lompat ke Bagian

1. Pemrosesan Lokal 2. Izin Akses Media 3. Retensi & Penghapusan 4. Kontak Resmi

1. Pemrosesan Media & File Lokal (On-Device Processing)

Aplikasi utilitas kami (seperti pengompres media dan alat bantu file) memproses seluruh berkas foto, video, atau dokumen secara langsung di dalam memori perangkat Anda:

  • Berkas media Anda tidak pernah diunggah ke cloud, server pengembang, atau perantara pihak ketiga mana pun.
  • Seluruh algoritma kompresi atau konversi berjalan menggunakan kemampuan CPU/GPU lokal ponsel Anda.

2. Izin Akses Media (Photo & Video Permissions)

Untuk menjalankan fungsi utilitas yang diminta, aplikasi memerlukan akses selektif ke berkas:

  • Pemilih Media (Android Photo Picker): Kami menggunakan sistem pemilih media bawaan Android terbaru sehingga aplikasi hanya membaca berkas spesifik yang dipilih oleh pengguna.
  • Izin Penyimpanan: Digunakan untuk menyimpan hasil berkas yang telah dikompres atau dikonversi ke direktori penyimpanan yang ditentukan oleh pengguna.

3. Kebijakan Penghapusan & Retensi Data

Karena kami tidak menyimpan file Anda di server eksternal, Anda memiliki kendali penuh atas file hasil pemrosesan. Anda dapat menghapus file hasil kapan saja melalui aplikasi Galeri atau File Manager ponsel Anda.

4. Kontak Resmi

Pertanyaan seputar kebijakan privasi aplikasi utilitas dapat dikirimkan ke rewizatech@gmail.com.
