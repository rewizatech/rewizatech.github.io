Kebijakan Privasi: Kasir Laris POS

Terakhir Diperbarui: 10 November 2026 · Efektif: Versi 1.0 ke atas

Kebijakan Privasi ini menerangkan bagaimana Rewiza Tech ("kami", "pengembang") mengelola, memperlakukan, dan melindungi data pengguna saat mengoperasikan aplikasi Android Kasir Laris POS. Kami berkomitmen penuh untuk menjunjung tinggi privasi pengguna sesuai dengan Kebijakan Data Pengguna Google Play (Google Play User Data Policy).

Lompat ke Bagian

1. Penyimpanan Lokal 2. Izin Perangkat 3. Keamanan Data 4. Penghapusan Data 5. Pihak Ketiga 6. Kontak Resmi

1. Prinsip Utama: Arsitektur Offline-First & Penyimpanan Lokal

Kasir Laris POS dirancang dengan filosofi privasi terdepan (privacy-by-design). Seluruh operasional pembukuan bisnis Anda dijalankan secara offline murni pada perangkat Anda:

  • Data Katalog & Stok Barang: Nama produk, harga jual, harga modal, dan kuantitas stok disimpan secara eksklusif dalam database lokal perangkat Anda (SQLite/Room).
  • Data Transaksi Penjualan: Nilai transaksi, tanggal transaksi, nomor invoice, dan riwayat pesanan hanya tersimpan di memori lokal ponsel Anda.
  • Nol Transmisi Server Pengembang: Kami TIDAK MENGUMPULKAN, TIDAK MENYIMPAN, DAN TIDAK MENGIRIMKAN data penjualan, data pelanggan toko, maupun rekaman finansial Anda ke server kami atau server pihak ketiga mana pun.

2. Izin Akses Perangkat Android (Permissions)

Aplikasi hanya meminta izin yang mutlak diperlukan untuk mengaktifkan fungsionalitas inti yang diminta oleh pengguna:

  • Kamera (android.permission.CAMERA) — Bersifat Opsional: Hanya digunakan ketika Anda memilih untuk memindai kode batang (barcode) atau QR Code barang dagangan. Aliran kamera diproses secara lokal dan seketika (real-time on-device processing). Kami tidak mengambil foto pengguna, tidak merekam video, dan tidak menyimpan tangkapan kamera.
  • Penyimpanan Dokumen (Storage Access): Digunakan murni saat Anda menggunakan fitur "Simpan / Ekspor Laporan Transaksi" ke format PDF atau dokumen internal di memori penyimpanan perangkat Anda.
  • Transparansi Perangkat Tambahan: Pada rilis versi 1.0, aplikasi TIDAK meminta izin Bluetooth, tidak meminta izin lokasi latar belakang (Background Location), serta tidak mengakses daftar kontak atau buku telepon Anda.

3. Keamanan Data (Data Security)

Karena seluruh data tersimpan pada perangkat Anda, keamanan data dilindungi oleh arsitektur keamanan bawaan sistem operasi Android melalui mekanisme Application Sandbox. Artinya, aplikasi lain yang terpasang di ponsel Anda tidak dapat membaca database internal Kasir Laris tanpa izin resmi sistem operasi.

4. Prosedur Penghapusan Data (Data Deletion Policy)

Sesuai dengan ketentuan transparansi Google Play Store, pengguna memiliki kendali mutlak untuk menghapus seluruh data mereka kapan saja:

  • Penghapusan Total: Anda dapat menghapus seluruh basis data transaksi dan katalog barang secara permanen dengan membuka menu Pengaturan Android → Aplikasi → Kasir Laris → Penyimpanan & Cache → Hapus Data (Clear Storage).
  • Pencopotan Aplikasi: Menghapus (uninstall) aplikasi Kasir Laris dari perangkat Anda akan secara otomatis menghapus seluruh database dan file terkait dari memori perangkat secara permanen.

5. Layanan Pihak Ketiga & Privasi Anak

Aplikasi ini didistribusikan melalui Google Play Store dan dapat menggunakan komponen standar Google Play Services murni untuk keperluan pengecekan integritas aplikasi serta penyaluran pembaruan aplikasi resmi melalui Google Play.

Kasir Laris POS ditujukan khusus untuk pemilik usaha, pengelola toko, dan staf kasir. Aplikasi tidak secara sengaja mengumpulkan atau menargetkan data pribadi anak-anak di bawah usia 13 tahun (kepatuhan COPPA).
