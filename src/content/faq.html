Pertanyaan yang Sering Diajukan

Temukan jawaban atas pertanyaan umum seputar aplikasi, privasi data, dan dukungan teknis dari studio pengembang Rewiza Tech.

1. Apakah semua aplikasi Rewiza Tech dapat digunakan tanpa internet (offline)?

Dukungan offline bergantung pada desain masing-masing produk. Khusus Kasir Laris POS, aplikasi dirancang dengan pendekatan offline-first sehingga transaksi kasir dan pengelolaan stok berjalan langsung pada penyimpanan lokal perangkat tanpa bergantung pada koneksi internet.

2. Di mana data transaksi Kasir Laris disimpan?

Pada versi pertama, seluruh katalog produk, stok, dan riwayat transaksi disimpan secara lokal di database perangkat Android Anda (SQLite/Room) dan dilindungi oleh sistem sandbox bawaan Android. Pengembang tidak mengumpulkan maupun mengirim data transaksi toko Anda ke server eksternal.

3. Bagaimana cara mencetak struk transaksi di Kasir Laris?

Pada versi rilis 1.0, setelah transaksi selesai, pratinjau struk digital lengkap ditampilkan langsung di layar ponsel. Integrasi printer thermal fisik ditunda pada versi pertama agar fokus pada kestabilan pencatatan transaksi lokal.

4. Bagaimana cara mengunduh aplikasi resmi Rewiza Tech?

Kunjungi halaman Katalog Aplikasi untuk memantau informasi produk terbaru. Tautan unduhan Google Play Store resmi akan ditambahkan di katalog setelah listing publik tersedia dan terverifikasi.

5. Bagaimana jika saya berganti HP atau ingin menghapus data aplikasi?

Karena data tersimpan secara lokal di perangkat, pastikan Anda mencadangkan atau mengekspor laporan penting sebelum mengganti HP atau mencopot aplikasi. Untuk menghapus data secara permanen, Anda dapat menggunakan menu Pengaturan Android → Aplikasi → Kasir Laris → Hapus Data atau uninstall aplikasi.
