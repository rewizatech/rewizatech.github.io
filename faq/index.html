Pertanyaan yang Sering Diajukan

Temukan jawaban atas pertanyaan umum seputar aplikasi, privasi data, dan dukungan teknis dari studio pengembang Rewiza Tech.

1. Apakah aplikasi Kasir Laris benar-benar bisa digunakan tanpa internet?

Ya, 100% offline. Kasir Laris dirancang dengan arsitektur offline-first. Seluruh fitur pendaftaran produk, pencatatan transaksi kasir, kalkulasi kembalian, dan rekap penjualan berjalan murni di memori lokal ponsel Anda tanpa memerlukan kuota data atau koneksi WiFi.

2. Apakah data transaksi saya aman dan tidak dilihat orang lain?

Sangat aman. Karena tidak ada sinkronisasi ke server kami, data penjualan Anda tidak pernah keluar dari ponsel Anda. Data dilindungi oleh sistem keamanan Android sandbox sehingga aplikasi lain di ponsel Anda tidak dapat membacanya.

3. Bagaimana cara mencetak struk transaksi di Kasir Laris?

Pada versi rilis 1.0, setelah transaksi selesai, struk digital lengkap akan otomatis ditampilkan di layar ponsel. Anda dapat memperlihatkan struk ke pelanggan atau memilih opsi simpan/ekspor dokumen PDF. Integrasi printer thermal Bluetooth eksternal ditunda pada build awal demi menjaga kestabilan aplikasi.

4. Bagaimana cara mengunduh aplikasi resmi Rewiza Tech?

Seluruh aplikasi kami didistribusikan secara resmi melalui Google Play Store. Kunjungi halaman Katalog Aplikasi untuk melihat status ketersediaan dan tautan unduhan langsung ke Google Play.

5. Bagaimana jika saya berganti HP atau menghapus aplikasi?

Karena seluruh data tersimpan secara lokal, kami sangat menyarankan Anda untuk rutin memanfaatkan fitur ekspor/backup data ke kartu memori atau memindahkan file cadangan secara berkala agar riwayat pembukuan toko Anda tetap aman jika HP hilang atau rusak.

6. Bagaimana cara menghubungi tim pengembang jika ada kendala?

Anda dapat langsung menghubungi kami melalui WhatsApp di 0831-5566-2121 atau mengirimkan pesan ke email resmi kami di rewizatech@gmail.com.
